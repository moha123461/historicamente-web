Política de privacidad

Última actualización: 9 de noviembre de 2026

1. Sobre HistóricaMente AutoStudio

HistóricaMente AutoStudio es una herramienta de automatización para producir y publicar vídeos educativos de historia en YouTube.

2. Acceso a Google y YouTube

La aplicación utiliza la autorización OAuth de Google y el permiso youtube.upload para subir vídeos a una cuenta de YouTube autorizada.

3. Uso de los datos

Las credenciales se utilizan exclusivamente para autenticar la conexión con YouTube y realizar las publicaciones autorizadas.

4. Seguridad

Los tokens de autorización se almacenan en GitHub Actions Secrets y no se incluyen en el código público de esta web.

5. Revocación del acceso

El usuario puede revocar el acceso desde su cuenta de Google .

6. Servicios de terceros

La aplicación utiliza servicios de Google, YouTube y GitHub para su funcionamiento. Estos servicios tienen sus propias políticas de privacidad.

7. Contacto

Para consultas sobre privacidad, utiliza los canales de contacto publicados por HistóricaMente.
